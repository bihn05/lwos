# 31 — 82540EM（开发用，模拟器里的 e1000）

## 目标

在 QEMU/Bochs 里把 e1000 家族的**共用部分**（`e1000_ring.c`）调通，给真机的 82567LM 打底。

## 现状

无。

## 依赖

- 前置：[20 PCI 枚举](20-pci-enum.md)、[30 NETDEV](30-net.md)。
- 后继：[32 82567LM](32-net-i82567lm.md) 复用这里调通的 `e1000_ring.c`。

## 识别

- PCI ID **8086:100E**，class 02/00。QEMU 默认的 `-device e1000` 就是它。
- 注意：QEMU 的 `-device e1000e` 模拟的是 **82574L（8086:10D3）**，不是 82567，别被名字误导。

## 寄存器（BAR0，MMIO）

家族共用，放 `e1000_regs.h`：

| 偏移 | 名字 | 要用的位 |
|---|---|---|
| 0x0000 | CTRL | bit5 ASDE、bit6 SLU（强制链路上线）、bit26 RST |
| 0x0008 | STATUS | bit1 LU（链路已上线） |
| 0x0014 | EERD | 读 EEPROM：bit0 START，bit4 DONE，[15:8] 地址，[31:16] 数据 |
| 0x00C0 | ICR | 读清 |
| 0x00D0 / 0x00D8 | IMS / IMC | 轮询模式下向 IMC 写 0xFFFFFFFF，全部屏蔽 |
| 0x0100 | RCTL | bit1 EN、bit4 MPE、bit15 BAM（收广播）、[17:16] BSIZE（00 = 2048）、bit26 SECRC（剥掉 CRC） |
| 0x0400 | TCTL | bit1 EN、bit3 PSP、[11:4] CT = 0x0F、[21:12] COLD = 0x40（全双工） |
| 0x0410 | TIPG | 全双工铜缆：0x0060200A |
| 0x2800/04/08 | RDBAL/RDBAH/RDLEN | 收环基址、长度（字节，128 的倍数） |
| 0x2810/18 | RDH/RDT | 收环头/尾 |
| 0x3800/04/08 | TDBAL/TDBAH/TDLEN | 发环 |
| 0x3810/18 | TDH/TDT | 发环头/尾 |
| 0x5200 | MTA[128] | 组播表，全部清零 |
| 0x5400/04 | RAL0/RAH0 | 本机 MAC；RAH0 bit31 AV（地址有效） |

## 描述符（legacy 格式，16 字节）

```c
typedef struct { QWORD addr; WORD len; WORD csum; BYTE status; BYTE errors; WORD special; } E1000_RXD;
typedef struct { QWORD addr; WORD len; BYTE cso; BYTE cmd; BYTE status; BYTE css; WORD special; } E1000_TXD;
```

- RX status：bit0 DD（已写回），bit1 EOP。
- TX cmd：bit0 EOP、bit1 IFCS（硬件补 FCS）、bit3 RS（完成后写回 DD）。TX status bit0 DD。

## 流程

**初始化**

1. PCI 命令寄存器置 Memory Space + Bus Master。
2. CTRL.RST = 1，等它自己清零（再多等 1ms）。
3. IMC = 0xFFFFFFFF，读一次 ICR 清掉残留。
4. MAC：用 EERD 读 EEPROM 字 0、1、2（小端，各 2 字节）。写进 RAL0/RAH0，并置 AV。
5. MTA 全清。
6. 建收环：N 个描述符（例如 32，32×16 = 512 字节，是 128 的倍数），每个指向一块 2KB 缓冲。RDH = 0，RDT = N−1。
7. RCTL = EN | BAM | SECRC | BSIZE_2048。
8. 建发环：N 个描述符清零。TDH = TDT = 0。
9. TCTL = EN | PSP | CT | COLD；TIPG。
10. CTRL |= SLU | ASDE，轮询 STATUS.LU。

**发送**：填 `txd[tdt]` = {缓冲地址, 长度, cmd = EOP|IFCS|RS}，TDT = (tdt+1) % N。
第一版可以直接轮询这个描述符的 DD 位，等它发完再返回。
帧长小于 60 字节时，**自己补零到 60**（PSP 位也会帮着补，但不要依赖它）。

**接收**：看 `rxd[(rdt+1)%N].status` 的 DD 位。置位了就把数据拷出来，清 status，把 RDT 推进到这个描述符。

## 里程碑

即 [30](30-net.md) 的 N1–N3。

## 容易踩的坑

- RDT 初值是 N−1 而不是 N：头尾相等表示"没有可用描述符"，硬件就不收了。
- 描述符里的 `addr` 是 64 位，高 32 位必须写 0。
- 忘了置 Bus Master：寄存器能读写，但永远收不到、发不出，而且**没有任何错误提示**。
