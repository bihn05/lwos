一、关于 LWOS

LWOS 是一个面向 CNC（计算机数控）铣削设备的业余操作系统。外观和操作感受参考 IBM-PC， 但系统本身不依赖 BIOS。固件支持（自定义 BIOS、IBM 兼容机）属于另一个独立项目，不在本项目范围内。

所有代码都是手工编写的。目前处于第二版（v2）的重写阶段，仓库正在从零开始重建， API 和目录结构随时可能变更，不另行通知。

磁盘格式：FAT32 + 自制 LOADER。
运行环境：QEMU 或 Bochs 模拟器。

二、目前可用的功能

  • MBR -- 引导系统盘，读取分区表。
  • FAT32（只读） -- 简化版 FAT32 读取，实现在 LOADER 里。以后会做多级目录和读写。
  • tools/mkfat -- 宿主机上用来制作 FAT 镜像的小工具，C 语言。
  • MONITOR.BIN -- 调试器兼命令行，启动后进入这里。

其余部分（shell、实用工具、CNC 相关功能）还在规划中，尚未实现。

三、启动链

开机以后依次经过以下几个阶段：

MBR (0x7C00)
  |
  v
STAGE2 (0x900, 实模式)
  |-- 收集 E820 内存表      -> 0x8000
  |-- 收集 VBE/EDID/显卡信息 -> 0x9000
  |-- 留下 BIOS 跳板         -> 0xA000
  `-- 读 FAT32, 找到 LOADER.BIN -> 0x10000, 进入保护模式
  |
  v
LOADER.BIN (0x10000)
  `-- 按 BOOT.INI 加载:
        ABI.BIN     -> 0x100000  (库映像)
        MONITOR.BIN -> 0x200000  (调试器 / 命令行)

说明：没有分页，所有设备目前都用轮询方式工作，没有定时器中断。

返回顶部

四、正在规划的

  1. MONITOR.BIN -- 仿照 MS-DOS 的 DEBUG.COM，但提供更多 ABI 调用。
  2. EDIT.EXE -- 仿照 MS-DOS 的 EDIT.COM 的文本编辑器。
  3. PCI 枚举、AHCI 驱动 -- 从硬盘读取程序。
  4. 网卡驱动 -- 82540EM（模拟器用）和 82567LM（真机用），用一根网线直连，不停机传文件。
  5. LWP 可执行格式、DLL -- 带重定位的程序加载。
  6. 图形界面 -- 从画布和填充矩形做起。
  7. 任务切换 -- 基于 GDT/TSS，放在最后做。

详细的计划见 总路线。

五、构建与运行

需要：

  • 有 make 的 Unix 类环境
  • C 编译器
  • QEMU 或 Bochs

在模拟器中构建并启动：

make run
