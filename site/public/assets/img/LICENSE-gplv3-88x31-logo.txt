Licence
-------
Per the "Copyright and license" section of that page, the official GPL, AGPL
and LGPL logos are in the public domain, and the page says outright:

    If you are releasing work under ... version 3 of the GNU GPL, LGPL, or
    AGPL, feel free to use these buttons on your site or in your application
    to advertise the license.

Public domain means there is no restriction on modifying them, so the
pixelated derivative below needs no permission. The design credit above is a
courtesy, not a condition.

Which file is which
-------------------
gplv3-88x31.png        The official artwork, byte for byte. Don't edit it — it
                       is the input tools/mkgpl.py reads, and the sha256 above
                       is how you tell it is still pristine.
gplv3-88x31-pixel.png  Derived: half size with BOX, blown back up with NEAREST
                       (each source pixel becomes a 2x2 block), then quantised
                       to 8 colours to drop the anti-aliasing. This is the one
                       index.astro renders, in the banner's bottom row.
                       Regenerate with `python3 tools/mkgpl.py`.

Deliberately the plain GPLv3 button, NOT gplv3-or-later-sm.png from the same
page: that one reads "OR LATER" and would misstate GPL-3.0-only.

Both files keep an alpha channel, so the background shows through the corners —
that is how the original is built. The badge sits on the banner, which is white.
